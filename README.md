# Почта · тест: обновления

Неофициальный личный экспериментальный Android-клиент почты.

[Скачать актуальный APK](https://github.com/nikitasever/spbu-mail-pilot-updates/releases/latest)

Установите APK поверх прежней версии. Аккаунты и задачи сохраняются. Начиная с 0.9.1 обновления доступны в приложении: **Настройки → Проверить обновление**. Android попросит разрешить установку из приложения и подтвердить её.

Здесь публикуются только APK и метаданные. Почтовых паролей, писем и вложений в репозитории нет. APK проверяет подпись, SHA-256 и номер версии до установки.

В 0.9.1 включены отправка писем и ответы с вложениями, отметки прочтения в ящике, открытие номера в стандартном приложении «Телефон», уведомления и обновления через интернет. SMTP и уведомления необходимо проверить с реальным ящиком на телефоне. Письма не становятся поручениями автоматически.

## Новое в 0.10.1

- В открытом письме рядом с именем отправителя — «Написать отправителю». Создаётся новое письмо с его адресом; «Ответить» сохраняет цепочку.
- Календарь → Подключить рабочий календарь: укажите название, HTTPS CalDAV-ссылку нужного календаря, логин и пароль. Для Mail.ru используйте пароль внешнего приложения. [Как получить ссылку и пароль](https://help.mail.ru/calendar-help/synchronization/thunderbird/).
- События сервера доступны для просмотра по месяцам. Локальные задачи и события отображаются рядом; изменения локальных записей остаются на телефоне. При ошибке обновления сохранённые события остаются доступными.
- Данные подключения зашифрованы и разделены по почтовым аккаунтам. «Отключить» удаляет подключение и кэш на телефоне; события на сервере сохраняются.

На реальном календаре подключение проверяется владельцем после ввода его ссылки и пароля на телефоне.
