Первый локальный прототип «Рабочей почты» для Windows 10/11 x64.

Установщик включает JVM-движок и runtime. Отдельный сервер, установка Java/Node/Rust и запуск терминала пользователю не нужны. Оболочка Tauri и движок общаются через приватные stdin/stdout; локальный HTTP-порт не открывается.

Работает первый сценарий: вход по IMAP/TLS, полный список папок, серверный поиск, пагинация и чтение по UID/UIDVALIDITY. Чтение не меняет Seen. Приложение использует существующее JavaMail-ядро; Android-исходники и APK не изменялись.

Это ранняя версия только для чтения. Пока нет сохранения пароля на следующий запуск, офлайн-почты, отправки/черновиков, открытия и скачивания вложений, календаря, контактов, Gemini и системных уведомлений. Имена вложений отображаются; кнопок несуществующей отправки или скачивания нет. Тексты HTML-писем преобразуются в текст, внешние изображения не загружаются.

Проверены протокол, отмена подключения/чтения, защита от запоздалых ответов, скрытие секретов в ошибках, завершение JVM по EOF. Браузерные проверки выполнялись на явно тестовом транспорте, не на пользовательском аккаунте. Windows-сборка проверяет вложенный runtime и IPC. Дополнительная проверка установки/окна записана в install-proof.json.

Работа с вашим реальным почтовым сервером пока не проверена. Установщик не подписан сертификатом Windows; это тестовый выпуск. Стабильные Android-выпуски не меняются.

Исходники соответствуют build-info.json. Приложенный Cargo.lock содержит точные зависимости выполненной Windows-сборки; для повторной сборки поместите его в desktop/src-tauri/ рядом с Cargo.toml.
