# 0.74-native.7 — исправления после проверки кода

Исправления в обоих вариантах APK:

- Тайм-аут и обрыв тела ответа после HTTP 200 теперь получают этап Google (G02/G03), а не прежнюю общую ошибку. Ошибки квоты и HTTP API сохраняют свой смысл; превышение лимита ответа обозначено отдельно.
- Отменённый или просроченный экспорт проверяется до открытия файла назначения на перезапись. Дублирующее сохранение во время копирования заблокировано; потоки закрываются при отмене, исходник не изменяется.
- Ожидающее сохранение через системный выбор файла восстанавливается при пересоздании Activity. Незавершённое копирование явно сообщает, что результат может быть неполным; старый URI не используется для следующего сохранения.
- Ограниченный предпросмотр длинного UTF-8 больше не переключает весь текст в Windows-1251 из-за обрезанного последнего символа. BOM, UTF-16 и старые Windows-1251-файлы сохранены.
- Вложенные письма message/global без имени теперь видны как EML и извлекаются без изменения байтов.

Подключение Gemini остаётся через 185.221.196.212:2053 с прежним закреплённым сертификатом. Пароли и ключи сохраняются. Стабильный канал обновлений не изменяется.

Проверки: воспроизведён и исправлен UTF-8-дефект; локальные регрессионные тесты экспорта, MIME/EML и полного TLS CONNECT/POST, включая задержку тела после HTTP 200; компиляция обоих вариантов, проверки тем и приватности. Поворот экрана/SAF и реальная работа Gemini на физическом телефоне здесь не проверены.
