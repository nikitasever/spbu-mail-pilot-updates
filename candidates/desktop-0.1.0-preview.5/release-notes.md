Windows 10 1903+ / Windows 11 x64 — предварительная версия 5.

Добавлен раздел «Календарь» на существующем Java-ядре CalDAV: обнаружение календарей, явный выбор одного из списка, день, неделя, месяц и повестка. Нажатие на день открывает всплывающий список с временем, названием, календарём, местом и раскрываемым описанием. Время Москвы, понедельник — начало недели. Неделя на границе месяцев загружает оба месяца. Повторения и исключения разбирает существующее ядро; для событий на весь день дата окончания исключительна.

Подключение требует HTTPS и отдельных данных входа календаря. Почтовый пароль автоматически не передаётся. «Подключить и запомнить» сохраняет один источник для текущего почтового ящика средствами Windows DPAPI. Можно обнаружить несколько календарей либо указать прямую ссылку на одну коллекцию. Пароль и закрытые URL не возвращаются в JavaScript. Переходы на другой origin запрещены; число редиректов внутри того же origin ограничено. Сохранённое подключение запрашивается после открытия раздела, не при входе в почту.

Календарь работает независимо от IMAP: почта и загрузки вложений доступны во время запроса. Есть отмена загрузки; поздние ответы не подменяют новый период или другой аккаунт. События пока находятся в памяти текущего сеанса. «Обновить» получает актуальные данные; при сбое старые данные остаются с предупреждением. Незагруженный день не объявляется пустым. «Отключить все календари» после подтверждения удаляет только локальное подключение, не события сервера.

Серверные события доступны только для чтения. Создание/изменение событий, локальные задачи и офлайн-кэш календаря пока не перенесены. Это не полный перенос возможностей APK. Пока нет контактов, Gemini, системных уведомлений, офлайн-почты, серверных черновиков и списка нескольких сохранённых аккаунтов.

Сохранены чтение почты без изменения Seen, реальные папки/поиск, независимые загрузки вложений, отправка с 10 секундами отмены до SMTP, защита от повторной отправки при неизвестном результате, независимая копия в «Отправленных», запоминание аккаунта и зашифрованное восстановление локального черновика с файлами. Установщик включает Java; отдельный сервер не нужен, локальный HTTP-порт не открывается.

Проверки: Java CalDAV через тестовый HTTP-перехватчик (обнаружение, повторения, Москва, границы, origin/XXE), независимая почта и отмена соединения; модель дат; браузерные сценарии подключения/выбора/всплывающего дня, устаревшие ответы, ошибки, узкое окно и очистка при выходе; регрессия почты, вложений, отправки и черновиков. Нативная сборка, шифрование DPAPI, установка, запуск окна, Unicode-путь и завершение JVM проверяются на Windows. Метаданные и скриншот установленного окна приложены.

Реальные IMAP/SMTP/CalDAV с пользовательскими учётными данными ещё не проверены; тесты не отправляют писем людям. Перед установкой закройте предыдущую версию. Установщик не подписан. Android-выпуски не меняются.

Исходники привязаны к sourceCommit в build-info.json. Приложенный Cargo.lock содержит точные зависимости сборки; для повторной сборки замените им desktop/src-tauri/Cargo.lock из архива.
