Windows 10 1903+ / Windows 11 x64 — предварительная версия 7.

Добавлена локальная адресная книга «На этом компьютере»: создание, изменение имени/адреса и удаление контактов с подтверждением. Доступна для любого подключённого почтового ящика; для серверов кроме mail.spbu.ru выбирается по умолчанию. Поиск и русский/латинский алфавит работают по всей загруженной книге, «Загрузить ещё» показывает следующие 50 записей. Предел — 5000 контактов на ящик. Требуется вход в почту; автономный вход без IMAP ещё не реализован.

Книга сохраняется через Windows DPAPI CurrentUser с контекстом владельца, отдельно для сочетания сервер/порт/логин. Записи сохраняются между запусками; после выхода контакты и поля формы убираются из интерфейса, зашифрованная книга остаётся на компьютере. Данные не помещаются в localStorage и не синхронизируются на телефон или сервер. DPAPI связан с профилем Windows; незашифрованного fallback нет.

Каждое изменение проверяет активную сессию и UUID-версию книги. Дубликаты адресов без учёта регистра отклоняются. Ошибка записи оставляет введённый текст. Конфликт блокирует сохранение устаревшей формы и оставляет её для копирования: нужно закрыть форму, перечитать книгу и открыть контакт заново. Ошибка расшифровки или повреждение не заменяют существующий файл новой пустой книгой. Сохранение выполняется атомарно; повторов без нажатия пользователя нет.

Закрытие изменённой формы требует подтверждения; «Остаться» получает первый фокус, Escape сохраняет правки. Удаление называет контакт и меняет только локальную книгу. Обычное закрытие окна учитывает и несохранённый контакт, и почтовый черновик через один существующий обработчик закрытия. Текущая запись блокирует закрытие до результата. Внезапное завершение сохраняет только уже подтверждённые изменения: контактная форма не является автоматически сохраняемым черновиком.

Сохранены серверные книги СПбГУ только для чтения, безопасное добавление получателя в текущий почтовый черновик, CalDAV-календарь со всплывающим списком событий дня, реальные папки/поиск, независимые загрузки вложений, SMTP с защитой от повторов и зашифрованное восстановление почтового черновика. Установщик включает Java; отдельный сервер поднимать не нужно.

Проверки: настоящая Windows DPAPI для записи/чтения книги, неверный владелец, дубликаты, версии, редактирование/удаление и повреждённый файл; браузерный тестовый store для создания, изменения, удаления, перезапуска, изоляции ящиков, ошибок, конфликтов, фокуса, подтверждений, закрытия окна с почтовым черновиком и узкой вёрстки. Пройдены регрессии почты/вложений/отправки/сохранения/календаря/серверных контактов. Установка, запуск окна, путь с кириллицей и завершение JVM проверены на Windows; доказательства и скриншот приложены.

Это не полный перенос APK: остаются импорт/экспорт контактов, серверное редактирование книг, офлайн-почта, серверные черновики, несколько сохранённых аккаунтов, запись событий/локальные задачи, Gemini и уведомления. Реальные IMAP/SMTP/CalDAV и справочник СПбГУ с пользовательским аккаунтом ещё не проверены. Перед установкой закройте предыдущую версию. Установщик не подписан. Android-выпуски не меняются.

Исходники привязаны к sourceCommit в build-info.json. Cargo.lock фиксирует зависимости сборки; для повторной сборки замените им desktop/src-tauri/Cargo.lock из архива.
