# 0.74-native.6 — доступный адрес Gemini-прокси и диагностика

- В обоих вариантах Compose адрес частного прокси изменён на 185.221.196.212:2053. Это дополнительный IP того же сервера. Старый адрес недоступен с телефона без VPN.
- Сохранены пароль, закреплённый сертификат и независимая проверка TLS Google. Почта и календарь по-прежнему подключаются напрямую.
- В разделе ИИ → Прокси появилась явная проверка соединения без ключа Gemini, писем и вложений. Ответ HTTP 404 на тестовом адресе допустим; ключ и модель эта проверка не подтверждает.
- Показаны отдельные безопасные ошибки подключения, TLS, пароля, туннеля и ответа Google. Доступны отмена и ограничение проверки 20 сек.; фон и смена аккаунта инвалидируют результат. Прямого автоматического повтора нет.

Проверки: локальный полный TLS CONNECT/POST, проверка сертификата и отказ при чужом сертификате, отделение заголовков прокси от запроса Google, отсутствие ключа и тела у диагностического запроса, классификация ошибок без утечки секретов; компиляция обоих APK и существующие проверки тем и приватности.

Владелец подтвердил доступность нового IP в браузере телефона без VPN и совпадение сертификата на том же сервере. Работа самого Gemini API в APK ещё требует проверки после установки.

Отдельный предварительный выпуск. Стабильный канал не меняется. Два APK — альтернативные интерфейсы одного приложения с прежней подписью; одновременно не устанавливаются.
