Windows 10 1903+ / Windows 11 x64 — предварительная версия 6.

Добавлен раздел «Контакты» для аккаунтов mail.spbu.ru: личная серверная адресная книга, подразделение и общий справочник СПбГУ. Используется существующее Java-ядро UniversityDirectory; источники, подразделение и права определяет сервер. Открытие раздела само не запрашивает контакты. Доступны «Загрузить», явный поиск имени/адреса, очистка поиска, полный русский/латинский алфавит и «Загрузить ещё». Поиск не отправляется во время набора IME. Страницы объединяются без дублей адресов, проверяются повторяющиеся курсоры; предел сеанса — 5000 контактов, после чего нужен более точный запрос.

«Написать» добавляет выбранный адрес в текущий редактируемый черновик, сохраняя текст, файлы и других адресатов. Повторный адрес не добавляется. Таймер ещё не начавшейся отправки отменяется; уже передаваемое/отправленное письмо и неизвестный результат не разрешают изменение получателей и не запускают повторную отправку.

Контакты загружаются отдельным HTTPS-транспортом, почта остаётся доступной. Есть отмена; поздние ответы после смены книги/поиска/аккаунта игнорируются. Ошибка оставляет уже полученные контакты того же запроса. Пароль активного ящика используется только для фиксированного https://mail.spbu.ru, без HTTP-редиректов. Ошибка входа в справочник не закрывает IMAP-сеанс. Нативный слой и JVM связывают запрос с владельцем, а нативный слой повторно проверяет сессию перед возвратом ответа.

Серверные книги доступны только для чтения. Контакты находятся в памяти и очищаются при выходе. Локальная книга, создание/редактирование, импорт контактов и адресные книги других провайдеров пока не перенесены. Реальное подключение к пользовательскому справочнику СПбГУ ещё не проверено.

Сохранены CalDAV-календарь с выбором календарей и всплывающими событиями дня, чтение/поиск почты, реальные папки, независимые загрузки вложений, SMTP с защитой от повторной отправки и зашифрованное восстановление аккаунта/черновика. Установщик включает Java; отдельный сервер не нужен, локальный HTTP-порт не открывается.

Проверки используют фикстуры: личная книга/подразделение/общий справочник, XIMSS-сеанс, страницы и фильтры, фиксированный HTTPS-origin, граница владельца, отсутствие команд записи, отмена сокета, независимость IMAP и ошибка авторизации. Браузер проверяет поиск/IME/алфавит, старые ответы, ошибки, страницы, безопасный текст, узкое окно и добавление получателей без потери черновика. Пройдены регрессии почты, вложений, отправки, сохранения и календаря. Windows проверяет нативную сборку/DPAPI, установку, запуск окна, Unicode-путь и завершение JVM; доказательства установки и скриншот приложены.

Это не полный перенос APK: остаются офлайн-почта, серверные черновики, несколько сохранённых аккаунтов, запись событий/локальные задачи, локальная книга контактов, Gemini и уведомления. Реальные IMAP/SMTP/CalDAV с пользовательскими учётными данными ещё не проверены. Перед установкой закройте предыдущую версию. Установщик не подписан. Android-выпуски не меняются.

Исходники привязаны к sourceCommit в build-info.json. Cargo.lock фиксирует зависимости сборки; для повторной сборки замените им desktop/src-tauri/Cargo.lock из архива.
