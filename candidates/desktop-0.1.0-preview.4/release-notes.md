Windows 10 1903+ / Windows 11 x64 — предварительная версия 4.

Добавлено запоминание одного аккаунта по явной опции «Запомнить аккаунт на этом компьютере». Пароль хранится через Windows DPAPI CurrentUser. При следующем запуске вход начинается отдельной кнопкой, пароль не возвращается в JavaScript и не подставляется в поле. «Забыть сохранённый пароль» удаляет запись аккаунта, но сохраняет зашифрованный черновик. Автоматического входа и сетевых запросов за пользователя нет.

Один локальный черновик на host/port/user теперь сохраняется между запусками: текст, адресаты, параметры SMTP, заголовки ответа и выбранные файлы. Метаданные и каждый файл зашифрованы отдельно, с привязкой контекста к владельцу и ID. Автосохранение текста не шифрует заново большие файлы. Временные рабочие копии вложений остаются обычными файлами в приватной папке процесса для JavaMail; постоянная копия зашифрована. DPAPI привязан к профилю пользователя Windows, поэтому перенос зашифрованных файлов на другой профиль не является способом переноса данных.

Свернуть письмо означает сохранить его. Удаление черновика вынесено в отдельную кнопку с подтверждением. Выход и обычное закрытие окна сначала сохраняют изменения; при ошибке текст остаётся в памяти и пользователь видит предупреждение. Только последняя успешно сохранённая версия переживает аварийное завершение. Ошибка расшифровки не удаляет данные молча: можно повторить восстановление или явно удалить сохранённую копию. Single-instance предотвращает параллельные экземпляры, пишущие в одно хранилище.

Восстановление происходит после подтверждённого входа только для текущего ящика и никогда не возобновляет отправку или десятисекундный таймер. Состояния pending/unknown и SMTP-квитанция сохраняют блокировку повтора после сбоя. Подтверждённая отправка восстанавливается только для чтения; наличие серверной копии в «Отправленных» после восстановления отдельно не проверяется.

Сохранены SMTP/TLS или обязательный STARTTLS, десять секунд отмены до начала SMTP, защита от неизвестного результата, независимая копия в «Отправленных», чтение без изменения Seen и загрузка вложений с прогрессом. До 10 исходящих файлов, суммарно до 100 МиБ. Установщик включает Java; отдельный сервер не нужен, локальный HTTP-порт не открывается.

Проверки Windows используют настоящий DPAPI: шифрование/расшифровка, отсутствие открытого текста, неверный контекст, повреждение, пустые данные, восстановление текста/файлов и блокировок отправки. Проверки браузера используют тестовое хранилище: повторный вход без передачи сохранённого пароля в JavaScript, восстановление после перезагрузки окна, сохранение текста при ошибке, изоляция аккаунтов и отдельное удаление пароля. Установка, окно и завершение JVM проверены на Windows; метаданные и скриншот приложены. Реальные IMAP/SMTP с пользовательским ящиком ещё не проверены; тесты не отправляют писем людям.

Пока нет нескольких сохранённых аккаунтов в списке, серверных черновиков/синхронизации, офлайн-почты, календаря, контактов, Gemini и уведомлений. Перед установкой закройте предыдущую версию. Установщик не подписан. Android-выпуски не меняются.

Исходники привязаны к sourceCommit в build-info.json. Приложенный Cargo.lock содержит точные зависимости сборки; для повторной сборки замените им desktop/src-tauri/Cargo.lock из архива.
