Исправлен неполный список папок в обоих вариантах Compose.

Причина: при открытии выбора показывались только папки из кэша открытых ранее писем. Если открывали только «Входящие», других папок в меню не было; полный IMAP LIST выполнялся лишь по ручному обновлению.

- Меню автоматически запрашивает полный список реальных папок сервера при открытии. Это относится и к выбору папки для перемещения письма.
- Серверный список сохраняется отдельно от загруженных страниц писем в существующем зашифрованном кэше каждого аккаунта. Наличие «Отправленных» или «Черновиков на сервере» в меню не требует скачивания писем из них.
- Во время загрузки виден этап запроса, при отсутствии сети — сохранённый список и сообщение об ошибке. Подписи различают серверный и сохранённый списки; имя папки не выдаётся за наличие её писем офлайн.
- Названия/регистр/вложенность папок сохраняются. Вымышленные серверные Sent/Drafts не создаются. При обновлении каталога удалённые сервером папки не возвращаются из старых страниц писем.
- Поддерживается существующий кэш без миграции/удаления данных; размеры каталога и имена проверяются до записи. Отключение офлайн-доступа запрещает сохранение нового каталога.

Проверки: сохранение полного каталога и повторное чтение без писем Sent/Drafts, замена списка после удаления папки, сохранение Unicode и регистра, защита от изменения возвращённого снимка, отказ при некорректных/слишком больших списках, совместимость старого кэша; IMAP LIST-фикстура с исключением невыбираемых контейнеров. Android-сборки и остальные регрессии выполняются для обоих вариантов.

Полный список конкретного пользовательского сервера на телефоне здесь не проверяли. В предыдущем APK для запроса можно нажать ↻ рядом с заголовком «Папки»; в этой версии запрос автоматический.

Все исправления native.9 включены. Два APK — альтернативные интерфейсы с тем же пакетом и подписью: без -original — Gemini, с -original — исходный Compose. Устанавливайте свой вариант поверх текущего, не удаляя приложение.

Отдельный тестовый выпуск; стабильный канал не меняется.
