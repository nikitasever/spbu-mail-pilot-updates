# 0.74-native.2 — календарь: шторка дня и повестка

Отдельное тестовое обновление 0.74-native.1; стабильный канал 0.73 не меняется.

- В неделе и месяце нажатие на день открывает всплывающую шторку расписания; под сеткой список не дублируется. Шапка и действия закреплены, длинный список прокручивается.
- Повестка охватывает 14 дней от выбранной даты, со сдвигом на 14 дней и загрузкой обоих месяцев при необходимости.
- Поиск ограничен текущим периодом; пустой поиск не выдаётся за отсутствие всех календарей.
- В ячейках возвращены счётчики событий/задач, сегодняшний день отмечен рамкой.
- Добавлены явная кнопка «Сегодня», выбор даты и создание задачи на выбранную дату, также из шторки дня.
- Задача использует прежний редактор, сохранение и напоминания. Отмена возвращает к календарю без записи. Отключённые задачи скрыты.
- Снова отображаются состояние копии/ошибки источников и пояснение времени Москвы. Обновление не подключает новые CalDAV-источники автоматически.
- Переключатели масштаба помещаются отдельной строкой; интерфейс сохраняет светлую и тёмную темы.
- Прямой Gemini сохранён. Добавлены безопасные сообщения об отказе Google по региону, DNS, тайм-ауте и TLS. Обход региональных ограничений и посредники не добавлены; работа из РФ без VPN не гарантируется.

Подключение/отключение источников, локальное редактирование и связи с письмами сохранены. Серверные события остаются только для чтения — CalDAV PUT/DELETE не добавлены.

Проверки: арифметика периодов, границы месяцев/года, високосный февраль, диапазон поиска, скрытые задачи, отмена редактора, существующие связи с письмами и host-превью режимов календаря. Реальная CalDAV-синхронизация и телефон не проверены.

Версия 0.74-native.2, versionCode 91, пакет ru.local.spbumailpilot. Подпись прежним release-ключом: обычное обновление поверх 0.74-native.1. С прежним debug APK Gemini подпись несовместима; не удаляйте приложение с нужными данными ради проверки.
