# 0.74-native.3 — приватный прокси только для Gemini

Отдельный тестовый выпуск, стабильный канал не меняется.

Два варианта интерфейса:
- `spbu-mail-pilot-0.74-native.3.apk` — оформление Gemini, с календарём из native.2.
- `spbu-mail-pilot-0.74-native.3-original.apk` — наш исходный Compose.

Оба APK имеют одинаковый packageId ru.local.spbumailpilot и подпись: это альтернативные
варианты одного приложения, не два приложения для параллельной установки. Устанавливайте
выбранный вариант. versionCode 92; подпись прежним release-ключом. Не удаляйте приложение
с нужными данными ради смены варианта. Старый debug APK Gemini подписан другим ключом.

В настройках «ИИ · Gemini» добавлен блок «Прокси только для Gemini»:
- фиксированный сервер пользователя 79.137.206.221:19443, логин gemini;
- сохранение пароля включает маршрут; удаление пароля возвращает прямое подключение;
- пароль вводится на телефоне, хранится AES-GCM с Android Keystore и не показывается;
- TLS до прокси проверяет закреплённый отпечаток сертификата пользователя;
- внутри туннеля Google HTTPS проверяется отдельно системным хранилищем сертификатов;
- ключ Google не передаётся в заголовках CONNECT, прокси не расшифровывает содержимое;
- почта, отправка, CalDAV, контакты и вложения идут прежними прямыми маршрутами;
- при ошибке прокси нет автоматического прямого повтора; настройки отменяют текущие запросы.

VPN на телефоне для этого маршрута не требуется. Xray/3x-ui не меняются.
Сервер установлен пользователем; на нём требуется доступность TCP 19443 с телефона.
Отпечаток закреплён по предоставленному пользователем снимку вывода OpenSSL.
Сертификат выдан на 365 дней; его обновление потребует обновления закреплённого отпечатка.
Секретный пароль и ключ Gemini в APK/исходниках отсутствуют.

Проверены локальные TLS-фикстуры: верный pin, отклонение чужого сертификата до передачи
данных, авторизованный CONNECT внутри TLS, отсутствие API-ключа в CONNECT, независимый
TLS Google. Проверены отмена, отсутствие повтора, парсер и приватность состояния; выполнены
проверки компиляции/тем интерфейса. Живой Gemini с реальным ключом, внешний firewall и сеть
телефона не проверялись. Доступность Google с конкретного IP не гарантируется.

В приложенных previews.zip — ранее проверенные экраны календаря, не новые снимки прокси.
