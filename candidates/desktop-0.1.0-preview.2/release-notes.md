Локальная почта для Windows 10 1903+ / Windows 11 x64 — предварительная версия 2.

Добавлено сохранение вложений через системный диалог Windows, с прогрессом, отменой и повтором при ошибке. Вложения находятся над текстом письма. Панель загрузок остаётся видна при смене папок и писем; загрузка работает через отдельное IMAP-соединение и не занимает очередь чтения. Предел файла — 100 МиБ. Если полный размер неизвестен, процент не выдумывается. Временные файлы удаляются после операции, а существующая цель заменяется только после успешного копирования.

Сохранённый документ можно открыть отдельной кнопкой в системной программе Windows. Поддерживаются PDF, офисные документы, изображения, архивы и пересланные письма .eml/.msg при наличии соответствующей установленной программы. Встроенного просмотрщика .eml пока нет. Исполняемые файлы и активное содержимое можно сохранить; кнопка открытия для них не показывается. Приложение не открывает полученный файл автоматически.

Вход по IMAP/TLS, полный список папок, серверный поиск, пагинация и чтение работают как в первом прототипе. Статус прочтения на сервере не меняется. Пароль остаётся только в памяти сеанса. При выходе загрузки отменяются, панель и доступ к кнопкам открытия очищаются; явно сохранённые пользователем файлы остаются в выбранных папках.

Установщик включает Java; отдельный сервер или установка Java/Node/Rust не нужны. Оболочка и движок общаются через приватные stdin/stdout, без локального HTTP-порта.

Проверены ядро/отмена/независимость очередей, интерфейс прогресса/повтора/переходов на тестовом транспорте, защита существующего файла при ошибке, ограничения открытия файлов, установка Windows, запуск из папки с кириллицей и завершение JVM после закрытия окна. Данные install-proof.json и windows-login.png относятся к установленному приложению. Работа с вашим реальным почтовым сервером ещё не проверена.

Пока нет отправки и черновиков, сохранения аккаунта на следующий запуск, офлайн-почты, календаря, контактов, Gemini и уведомлений. Установщик не подписан сертификатом Windows. Android-выпуски не меняются.

Исходники привязаны к sourceCommit в build-info.json. Отдельный Cargo.lock содержит точные зависимости Windows-сборки; для повторной сборки замените им desktop/src-tauri/Cargo.lock из архива.
