# 0.74-native.5 — календарь и локальный просмотр вложений

- Частный Gemini-прокси: адрес подключения исправлен на фактический порт сервера 2053. Проверка из РФ без VPN ещё требуется.
- Календарь: время в отдельной колонке, цветная линия, полные названия и место события; описание раскрывается отдельной кнопкой.
- Нажатие на день недели/месяца открывает список событий во всплывающей панели с закреплёнными заголовком и действиями «Задача» / «Событие» в обоих вариантах Compose.
- Встроенный локальный просмотр пересланных писем .eml: отправитель, получатели, тема, текст и вложения внутри письма. Вложения находятся перед текстом.
- Единое открытие вложений из письма и библиотеки файлов. Текст, изображения и список ZIP доступны внутри приложения; для остальных форматов предусмотрены внешнее приложение и сохранение.
- Безопасность: локальный просмотр под общей блокировкой приложения; HTML не запускает JavaScript и не загружает удалённые картинки. Ограничены размер, глубина MIME и объём текста.

Это отдельная тестовая сборка. Работа Gemini через частный прокси без VPN пока не подтверждена на телефоне; изменение календаря и просмотра файлов не исправляет сетевое подключение автоматически.

Проверки: JVM-тесты MIME/EML, точного извлечения вложений, отмены, ограничений и путей; компиляция обеих версий, проверки тем и приватности, рендеры светлого/тёмного списка дня и повестки. Проверка на физическом телефоне остаётся необходимой.

Два APK — альтернативные интерфейсы одного приложения; одновременно не устанавливаются. Подпись сохранена. Стабильный канал обновлений не изменяется.
